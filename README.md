Интерактивное адаптивное веб-портфолио Fullstack-разработчика. Проект создан на чистом **Vanilla JS** и кастомном **CSS Grid/Flexbox**, демонстрируя навыки чистой верстки, оптимизации производительности и создания отзывчивых интерфейсов без тяжеловесных сторонних фреймворков.

---

## 🛠️ Технологический стек проекта

* **Frontend:** JavaScript (ES6+), HTML5, CSS3 (Grid & Flexbox).
* **Особенности:** Полная адаптивность, темная/светлая тема (с сохранением состояния), оптимизация анимаций.
* **Инструменты:** Git, GitHub, GitHub Pages.

---

## 🚀 Основные фичи сайта

* **💡 Переключатель тем:** Реализована плавная смена темного и светлого режимов (Dark/Light mode).
* **📱 Mobile-First & Responsive:** Идеальное отображение на любых экранах — от старых смартфонов до 4К-мониторов.
* **⚡ High Performance:** Максимальная скорость загрузки за счет отказа от лишних внешних зависимостей (в соответствии с практиками Google Lighthouse).
* **🗂️ Интерактивное портфолио:** Удобный каталог моих Pet-проектов со ссылками на исходный код и демо.
